# AI Slop Smells Catalog & Antidotes

This document catalogues the most common code and design smells generated by automated LLMs, along with strict corrective engineering standards.

---

## 1. Code Smells

### Smell 1: The Hollow Try-Catch
- **The Slop**:
  ```javascript
  try {
    saveData(data);
  } catch (err) {
    console.error(err);
  }
  ```
- **The Issue**: Swallows the failure silently; UI remains in an unknown state; the user has no feedback that saving failed.
- **The Antidote**:
  ```typescript
  try {
    await saveData(data);
    toast.success('Data berhasil disimpan');
  } catch (err) {
    const message = err instanceof Error ? err.message : 'Gagal menyimpan perubahan. Silakan coba lagi.';
    logger.error('Failed to save data payload', { error: err, payload: data });
    toast.error(message);
    setErrorState(message);
  }
  ```

### Smell 2: The Phantom Ellipsis (Lazy Truncation)
- **The Slop**:
  ```typescript
  export default function Dashboard() {
    // ... existing imports ...
    // ... keep existing header logic ...
    return <div>New Feature</div>;
  }
  ```
- **The Issue**: Breaks user copy-pasting, destroys existing code if accepted as whole file, causes syntax and runtime errors.
- **The Antidote**: Provide the complete, pristine file contents or use targeted patch replacements with exact line ranges.

### Smell 3: Synthetic Mock Arrays
- **The Slop**:
  ```javascript
  const users = [
    { id: 1, name: "User 1", email: "user1@example.com" },
    { id: 2, name: "User 2", email: "user2@example.com" },
    { id: 3, name: "User 3", email: "user3@example.com" },
  ];
  ```
- **The Issue**: Unrealistic lengths, lacking real character lengths, ignores edge cases (long names, unicode, missing avatars).
- **The Antidote**:
  ```typescript
  export const SAMPLE_STUDENTS: StudentRecord[] = [
    {
      id: "std_2026_0911",
      nisn: "0089123456",

    {
      id: "std_2026_0912",
  ```

## 2. Design Smells

### Smell 4: The Monotonous Purple Glow Card
- **The Slop**: Every element wrapped in `bg-slate-900 border border-purple-500/30 rounded-2xl p-6 shadow-purple-500/10` with zero functional meaning for the purple accent.
- **The Antidote**: Use semantic palette roles:
  - Surface base: Neutral tone calibrated to brand (warm zinc, crisp slate, cool stone).
  - Primary accent: Reserved exclusively for interactive calls to action and primary active states.
  - Border hierarchy: Hairline borders with opacity (`rgba(255, 255, 255, 0.07)` default, `rgba(255, 255, 255, 0.15)` on hover).

### Smell 5: Missing Micro-States
- **The Slop**: Buttons have a background color and nothing else. No hover color shift, no active scale click, no focus ring for keyboard navigation, no disabled visual treatment.
- **The Antidote**: Full state styling with CSS transitions (`transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)`):
  ```css
  .btn-primary {
    background: var(--brand-primary);
    color: #ffffff;
    box-shadow: 0 1px 2px rgba(0, 0, 0, 0.05);
    transition: transform 0.15s ease, background 0.15s ease, box-shadow 0.15s ease;
  }
  .btn-primary:hover {
    background: var(--brand-primary-hover);
    transform: translateY(-1px);
    box-shadow: 0 4px 12px rgba(37, 99, 235, 0.25);
  }
  .btn-primary:active {
    transform: translateY(0) scale(0.98);
  }
  .btn-primary:focus-visible {
    outline: 2px solid var(--brand-primary);
    outline-offset: 2px;
  }
  .btn-primary:disabled {
    opacity: 0.55;
    pointer-events: none;
    filter: grayscale(20%);
  }
  ```
